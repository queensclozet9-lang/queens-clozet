# Queen Clozet Portfolio

Create a premium, elegant, responsive portfolio website for a boutique and creative fashion/craft business called:

"Queen Clozet"

The website should feel like a high-end boutique portfolio rather than a typical ecommerce website.

The main purpose of the website is to:

1. Introduce Queen Clozet and its brand.

2. Showcase their boutique collections and creative work.

3. Explain all available services.

4. Showcase their craftsmanship and portfolio.

5. Allow customers to book an appointment.

6. Provide business location and contact information.

7. Help customers understand the different services, classes, and customization options.

IMPORTANT:

This is NOT an ecommerce website.

Do NOT add cart, checkout, online payment, product purchasing, or payment gateway functionality.

The appointment system is only for collecting customer information and appointment requests.

BRAND / VISUAL DIRECTION

--------------------------------------------------

Use the provided Queen Clozet logo as the primary brand logo.

The logo has a dark forest-green background with an elegant ivory/white handcrafted emblem.

Build the website's visual identity around this logo.

Primary visual direction:

• Deep forest green

• Warm ivory / cream

• Soft beige

• Subtle muted gold accents

• Dark charcoal for readable text

Avoid:

• Bright neon colors

• Excessive gradients

• Bright blue

• Pure white-heavy layouts

• Overly colorful UI

• Generic ecommerce design

• Excessive animations

• Cheap-looking fashion templates

The overall aesthetic should feel:

"Luxury Boutique + Handmade Craft + Feminine Elegance + Modern Minimalism"

The design should be sophisticated and timeless.

Use generous whitespace, elegant typography, subtle borders, soft shadows, refined spacing and large photography.

The photographs/collections should be the visual focus.

--------------------------------------------------

TYPOGRAPHY

--------------------------------------------------

Use an elegant serif font for major headings.

Suggested style:

• Headings: Playfair Display / Cormorant Garamond / similar luxury serif

• Body: Inter / DM Sans / Manrope / similar clean sans-serif

Use a combination of serif + modern sans-serif to create a premium editorial fashion feel.

Headings should be elegant but not excessively decorative.

TECHNICAL REQUIREMENTS

--------------------------------------------------

Build the website with a modern production-ready architecture.

Preferred stack:

React + Vite

Tailwind CSS

Modern component-based architecture

For appointment storage, use a proper backend/database such as Supabase if available.

The booking system must actually save appointment submissions to the database.

Implement basic validation:

• Required fields

• Valid phone number

• Valid email when provided

• Date cannot be in the past

• Appointment time must be within business hours

Prevent accidental duplicate submissions.

Show proper success and error states.
